# Proposal: 老人端视觉节奏优化

## Why

当前老人端页面虽然已经形成暖金品牌识别，但首页、用药和生活工具页重复使用居中标题、等分双列卡片、相同圆角阴影和统一上浮动画。页面之间缺少与任务对应的构图变化，形成明显模板感，也削弱了求助、用药和生活工具之间的操作优先级。

## What Changes

- 建立“共享视觉节奏 + 页面构图原型”的老人端设计规则。
- 首页改为非对称任务岛，保留四项功能但拉开求助、报平安和次级入口的权重。
- 生活工具页把日期牌作为日历入口，将其余工具组织为工具架，减少重复等分卡片。
- 后续将用药首页改为连续时间账本，用药详情改为单任务舞台。
- 调整进入动效，使动效跟随任务阅读顺序，而不是所有区块使用相同模板动画。

## Non-goals

- 不改变求助、报平安、用药、日历、计算器和手电筒的业务逻辑。
- 不改变已确定的暖金主色、SVG 图标体系和底部导航结构。
- 不引入照片、AI 插画、整页玻璃化或新的远程数据能力。

## Acceptance evidence

- 首页与生活页在 360×800 下具有明显不同的页面轮廓，并保持 48dp 点击区。
- 页面无横向滚动，固定导航不遮挡核心内容。
- 类型检查、现有单元测试、H5/App 构建与 OpenSpec 严格校验通过。
- 通过 DOM 与计算样式验证构图、可见文案、路由和减少动效，不生成截图。
