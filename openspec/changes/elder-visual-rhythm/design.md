# Design: 老人端视觉节奏优化

## 统一来源

统一感由 20px 页面边距、8pt 间距、暖金语义色、同一左上光源、圆线 SVG 和固定导航产生。页面不再通过重复同一张卡片模板取得统一。

## 变化语言

- 首页采用非对称 3 列任务岛：求助纵向跨两行，报平安横向跨两列，两个次级动作各占一格。
- 生活页把日期主牌作为日历入口；工具架只保留手电筒、放大镜和计算器，使用一张横向重点工具与两个次级工具。四项生活能力仍全部可见。
- 用药页使用连续纸面和时间轴；详情页使用单一服药舞台。上述页面在第二阶段落实。

## 材质与层级

每页只有一个暖金釉面主视觉。次级动作使用柔光纸面或低饱和语义色，阴影比主视觉低一级。主视觉使用一个不对称小圆角作为产品签名，避免所有组件轮廓完全相同。

## 动效

首页先出现状态，再出现求助与报平安，最后出现次级动作；生活页先出现日期，再出现工具架和下一安排。只动画 opacity 和 transform，减少动态效果下禁用动画。

## 适配

页面按 320–430px 宽度自适应。360×800 为主验收尺寸；文本不得因非对称格栅被截断，必要时保持中文动作名不换行。
