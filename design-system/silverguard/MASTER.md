# SilverGuard 视觉系统

## 方向

视觉方向为“暖金守护”。老人端以香槟金、奶油白和深墨色构成温暖可靠的界面；家属端沿用同一套圆角、投影方向、白色高光边和导航骨架，把角色主色替换为雾绿与松针绿。两端都使用“柔和悬浮实体”而非纯扁平卡片：老人端像温润金色釉面，家属端像柔光乳白纸面。高级感来自材质一致性、留白和少量有语义的色彩。

家属端采用 UI UX Pro Max 的 `Soft UI Evolution` 与 `Dimensional Layering` 方法：使用可测量对比度的柔和实体表面、单一光源和两级环境阴影；半透明效果只留给导航与固定操作层。纯 Neumorphism、整页玻璃化和后台仪表盘式密集布局均弃用。

家属端视觉参考保存在 [`docs/references/family-style-target.png`](../../docs/references/family-style-target.png)，只提取材质、色彩和空间关系，不复制其中的设备状态文案或首页告警列表。

## 材质

- 老人端玻璃表面：白色 70–86% 不透明度、背景模糊 12–18px、1px 白色高光边。
- 家属端统一画布：使用浅雾绿 `#E7EFEA`，整屏不切换底色；右上角可保留两道低透明圆环，不能形成新的内容分区。
- 家属端内容表面：常规卡片使用暖乳白 `#FFFEFB`，次级状态使用 `#F4F8F5`，平安/协同使用 `#DAEAE0`，高风险摘要使用 `#FAD1C8`。
- 家属端柔光实体：1px 白色高光边，左上白色 72% 柔光与下方松针绿 8.5% 环境阴影构成统一光源；不使用明显内阴影。
- 家属端玻璃表面：仅用于底部导航和固定操作条，白色 82–92% 不透明度、约 16px 背景模糊。
- 渐变：老人端用于暖金主视觉；家属端的主要操作使用稳定松针绿实体色，页面背景和内容卡不使用渐变。
- 珍珠釉实体：顶部白色内高光、底部深色柔和内阴影和大半径环境投影共同建立触感；用于主视觉和高优先入口。
- 柔光纸面：暖乳白实体表面、白色高光边和柔和环境投影；用于家属端人物卡、指标、趋势、列表和时间线。
- 微颗粒与同心光环：透明度保持在背景级，只用于消除大面积纯色的塑料感，不承载信息。
- 页面材质层级限制为暖金釉面、柔光纸面和玻璃导航三类，避免效果堆叠。

## 内容密度与产品语言

- 一个功能入口默认只由一个图标和一个动作名称组成，不追加同义说明。
- 行为约束并入动作名称，例如“长按求助”，不再拆成“紧急求助 / 长按 3 秒”。
- 每屏只突出一个主状态与一组主操作；不为填满空间增加卡片、标签或状态句。
- 只有会改变用户决定的状态、时间和来源才保留第二层文字。
- 核心任务页面不使用 AI 徽章、机器人、星光符号或“AI 为你……”式文案；必要时使用“状态摘要”“数据提示”等自然语言。

## 适老与告警边界

- 老人端主要正文至少 18px，辅助标签可使用 14–16px；Android 点击区域至少 48dp。
- 正文对比度至少 4.5:1；玻璃表面上的关键文字需按最终合成背景检查。
- 状态必须同时使用文字或图标，不能只依赖颜色。
- 危险操作、告警正文、确认弹窗使用实体表面，不在低透明玻璃上承载长文本。
- 动效只使用 150–300ms 的透明度、阴影和轻微位移变化，并支持减少动态效果。

## 页面策略

- 老人端首页：暖金状态主视觉、两项高优先入口、两项辅助入口、用药提醒、语音操作、玻璃底部导航。
- 老人端用药提醒：大时间和药品主视觉、单一确认服药动作、三行今日计划、联系家人入口。
- 家属端首页：顶部守护岛、单一整体状态、抽象守护圆环、联系老人/今日记录、一张活动趋势图和底部导航；设备与告警列表不在首页平铺。
- 家属端告警详情：告警结论、一句状态摘要、单一趋势图、处理时间线和随接管状态变化的固定操作条。
- 家属端守护页：按生活空间组织设备，使用生活化名称；技术编号、协议和后台配置不进入主界面。

## 构图节奏

- 统一感由 20px 页面边距、8pt 间距、暖金/松针绿语义色、同一左上光源、圆线 SVG 与导航骨架产生，不依赖重复同一张卡片模板。
- 老人端至少使用三类构图：非对称任务岛、连续时间账本、对象化工具舞台。相邻页面不能连续使用相同的等分双列网格。
- 每页只保留一个暖金或角色主色焦点；同组列表并入一张连续纸面，用分隔线和时间轴表达关系。
- 主视觉可使用 `28 / 28 / 28 / 10` 的不对称圆角作为克制的产品签名，普通纸面维持 18–20px，固定导航维持 22px。
- 动效按阅读顺序和任务权重错峰，禁止所有区块机械复用同一种上浮动画。

## 禁止项

- 通用 AI 插画、卡通老人和无信息价值的装饰图。
- 紫蓝 AI 渐变、彩虹图标、霓虹外发光。
- 全页面玻璃化、低对比灰字、所有卡片使用同一强阴影。
- 关键按钮小于 48dp、只用颜色表达风险、把 AI 建议写成医疗诊断。
- 按钮下方重复解释动作、模板化三层文案、无决策价值的小字和装饰标签。
- 真实室内照片、人物照片、监控画面和摄影背景；图表与状态层必须建立在纯色或抽象柔光表面上。
- 页面背景分段、顶部渐变色带、大面积装饰光斑、所有卡片同时玻璃化，或任何影响正文对比度的纹理。
