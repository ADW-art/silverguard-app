## 工具决策

项目停止使用自制 `SilverGuard UI Builder`，改用开源 [Figwright](https://github.com/awdr74100/figwright) 作为 Figma 本地读写桥接。Figwright 通过本机 MCP Server 与 Figma Desktop 开发插件连接，不使用 Figma REST API 配额，也不需要 Personal Access Token。

本机安装位置：

```text
E:\Tools\Figwright\v0.5.0\plugin\manifest.json
```

Codex 全局 MCP 名称：`figwright`。插件只连接当前打开的 Figma 文件；每次同步前必须检查文件名、当前页面和插件会话，禁止凭节点编号猜测目标。

## 同步规则

1. 先从代码和已确认设计文档读取当前事实，再读 Figma 页面结构。
2. 在独立且带日期的同步区域写入，验证完成前不删除或覆盖正式画板。
3. 页面必须保持 `360 × 800`，并保留可编辑文字、容器和图标层。
4. 同步后检查页面数、根画板尺寸、节点数量和裁切容器越界。
5. 用户评审通过后再把候选版提升为正式画板，并补原型跳转。
6. `01_Foundations`、`02_Components` 和家属端页面不随老人端同步自动覆盖。
