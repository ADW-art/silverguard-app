# 设计工作区

前端必须重新设计。本目录是设计信息的单一入口，不把原 `elder_care` 的页面截图、组件或样式当作实现依据。

## 设计顺序

1. 明确老人端、家属端和异常状态的信息架构。
2. 定义字体、颜色、间距、按钮尺寸和无障碍规则。
3. 输出首页、事件详情、告警处理、用药提醒、家庭协同五个关键流程。
4. 先确认设计，再建立 OpenSpec change 和实现任务。
5. 使用截图和 Android 真机完成验收。

## 设计原则

- 老人端优先可读性、可点击性、反馈明确和少步骤。
- 家属端优先信息层级、风险解释、行动按钮和时间线。
- 风险颜色不能只依靠颜色表达，必须同时使用文字、图标或状态标签。
- AI 内容必须标识“辅助建议”，不能伪装成医疗结论。
- 设计稿、实现和验收截图的页面命名保持一致。

后续 Figma 或其他设计产物应在本文件中记录链接、版本和对应的 OpenSpec change。
