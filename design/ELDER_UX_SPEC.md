# 老人端 UX 规格 v1

## 1. 产品目标

老人端第一版围绕“安全求助、日常提醒、家庭@联系、生活便利”设计。界面只呈现老人需要理解和操作的结果，不展示网关、传感器、网络连接等技术状态。

## 2. 已确认功能范围

### V1 必须完成

- 今日状态：显示“今日安好”“守护中”和状态同步结果。
- 长按求助：长按触发、倒计时取消、通知家人、显示接管进度和失败替代动作。
- 一键报平安：主动向已绑定家人同步“我很好”。
- 用药提醒：今日计划、当前提醒、确认服药、稍后提醒和漏服提示。
- 联系家人：展示 2–3 位重要联系人，支持直接拨打电话。
- 日常状态与状态播报：起床、休息、外出、回家等轻量记录；语音朗读今日状态和安排。
- 消息中心：用药提醒、家人回复、求助处理结果和必要系统通知。
- 生活工具：手电筒、日历日程、放大镜、大字计算器。
- 我的：已绑定家人、字号、提示音、语音播报、震动、高对比和防误触设置。

### 预留但暂不开放

- AI 文字与语音对话入口“聊一聊”。
- AI 日常陪伴、提醒解释、日程询问、语音备忘和家庭沟通摘要。
- 页面路由、对话消息结构和服务端 `ai-adapter` 接口使用功能开关控制；没有可用能力前不展示入口。

### 暂缓

- 医疗诊断、自动风险定级和自动修改用药计划。
- 实时监控画面、全天位置追踪和复杂健康仪表盘。
- 养老商城、支付、挂号、社交广场和多设备管理。
- 视频通话；V1 先完成电话联系闭环。

## 3. 信息架构

底部导航固定为四项：

1. **首页**：今日状态、长按求助、一键报平安、当前用药、联系家人。
2. **生活**：四项实用工具、今日日程，未来在此承载“聊一聊”。
3. **消息**：提醒、家人回复和处理结果。
4. **我的**：家庭成员、适老化设置、隐私权限和帮助。

主动守护是后台能力，不设置“设备状态”或“网络状态”页面。只有操作受影响时才显示结果型提示，例如“暂时未能通知家人，请直接拨打电话”。

## 5. 关键流程

### 5.1 紧急求助

首页长按求助 → 3 秒倒计时 → 发送求助 → 已通知家人 → 家人接管 → 显示接管人和联系入口。

必须覆盖：中途取消、重复触发、暂时无人响应、发送失败和直接拨打紧急电话。

### 5.2 一键报平安

首页点击报平安 → 显示发送中 → 家人已收到 → 首页更新时间更新。

失败时保留再次发送和直接联系家人两个动作。

### 5.3 用药提醒

收到提醒 → 查看药品与剂量 → 确认服药或稍后提醒 → 更新今日计划。

必须覆盖：即将开始、正在提醒、已完成、已错过和重复确认。

### 5.4 联系家人

首页进入联系人 → 选择家人 → 确认拨打 → 返回后显示最近联系时间。

联系人由家属侧维护，老人端不承担复杂编辑。

### 5.5 生活工具

生活页选择工具 → 请求必要权限 → 进入单任务界面 → 返回生活页。

权限被拒绝时使用自然语言解释用途，并提供“重新允许”和“返回”两个动作。

## 6. 文案与状态规则

- 首页主状态使用“今日安好”“需要关注”等生活化表达，不显示技术指标。
- 不出现“网关离线”“传感器故障”“错误码”等内部术语。
- 一个操作只解释一次；按钮下不重复添加同义小字。
- AI 不参与紧急求助、风险等级或用药决策；AI 不可用不能阻塞任何 P0 流程。
- 危险状态同时使用文字、图标和颜色，不能只依靠红色区分。

5. E07、E13–E16 辅助页面。
6. 连接三条演示原型：求助、用药、生活工具。
